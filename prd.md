
# Product Requirements Document (PRD)

## 1. Product Name
UniCard – Smart Student Identity Card System

## 2. Introduction
UniCard is a digital student card system designed
to manage and display student identity information.

It provides a digital ID card with student details,
a QR code and activity status.

## 3. Problem Statement
Traditional student ID cards contain limited information
and cannot easily display dynamic student activities.

Managing multiple student cards manually also requires
repeated design and development work.

## 4. Proposed Solution
UniCard provides a reusable digital student card system.

A single reusable React component displays different
student information based on the provided data.

## 5. Target Users
- College Students
- College Administrators
- Faculty Members

## 6. Functional Requirements

### Student Card
- Display student name.
- Display student photograph.
- Display student ID.
- Display department.
- Display academic year.

### QR Code
- Generate a QR code using the student ID.
- Allow student identity verification.

### Status Management
- Display student active status.
- Display attendance status.

### Dashboard
- Display multiple student cards.
- Search students by name or ID.
- View student details.

## 7. Non-Functional Requirements
- Simple user interface.
- Responsive design.
- Reusable components.
- Easy navigation.
- Fast loading.
- Maintainable code.

## 8. Technology Requirements
- Frontend: React.js
- Programming Language: JavaScript
- Styling: CSS
- Development Tool: VS Code
- Build Tool: Vite

## 9. Expected Outcome
A responsive digital student card system
that displays multiple student profiles
using reusable React components.

## 10. Future Scope
- Student login.
- Database integration.
- Real-time attendance.
- Library access management.
- Event participation tracking.
- Secure QR verification.
